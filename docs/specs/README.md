# Specs

Une spec par fonctionnalité, écrite et validée **avant** les tests et le code : `NNN-nom.md`.

```markdown
# NNN : titre

- Statut : brouillon | validée | livrée
- Lot : 0 à 5 (voir docs/PLAN.md)

## Contexte

Pourquoi, pour qui, ce qui existe déjà.

## Critères d’acceptation

- [ ] Étant donné…, quand…, alors… (vérifiable par un test ou une recette navigateur)

## Hors périmètre

Ce qu’on ne fait pas ici.

## Notes techniques

Fichiers touchés, données, risques.
```
